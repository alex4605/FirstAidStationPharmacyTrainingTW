# 還開著 STILL OPEN

戰時民防急救站的藥師（EMT-2）值班模擬——給台灣藥師用的網頁決策訓練遊戲。

對外轉診中斷第四天。你是地下避難室急救站裡唯一的藥師：核對處方、數藥調劑、回答其他職類的諮詢、做衛教、顧冷鏈與管制藥品、查核前來幫忙的民眾，並在 20:00 把藥局交給沒有藥師的夜班。白班結束後會產生行動後檢討（AAR），依 15 項職能逐項回饋。

空間、人員配置、藥品品項與七日儲備量取自衛福部 114 年「急救站設置參考指引」及其附件。

> 本系統為決策訓練輔助工具，不能取代任何正式訓練、認證課程或臨床指導。實務上的調劑、給藥與現場處置，應依所屬機構規範、相關法規、現行臨床指引及醫療指導醫師之指示為準。

## 怎麼玩

不需要安裝，也不需要建置：

- 直接用瀏覽器開啟 `index.html`，或
- 把整個資料夾放上任何靜態網站空間（例如 GitHub Pages）。

three.js 已放在 `vendor/` 內，沒有網路也能玩（字型會退回系統字型）。

| 操作 | 桌機 | 手機／平板 |
| --- | --- | --- |
| 移動 | `W` `A` `S` `D` | 畫面上的方向鍵 |
| 轉視角 | `Q` `E` | 畫面上的 ↺ ↻ |
| 拉遠／拉近 | `V` | — |
| 暫停／繼續 | `空白鍵` | 上方 ▮▮ |

### 讓整班跑同一場

網址後面的 `#seed=XXXXXX` 是這一場的亂數種子。同一個種子會編排出同一批幫手、同一組事件與時序，教官可以把連結發給整班，事後橫向比較 AAR。點畫面上方的「種子」即可複製連結。

## 檔案結構

```
index.html            頁面骨架，依序載入下列檔案
css/
  base.css            桌機版面與所有元件樣式
  narrow.css          手機／平板版面（由 JS 量測後掛上 html.narrow）
vendor/
  three.min.js        three.js r128（MIT）
js/
  core.js             亂數種子、共用小工具、場地分區
  data/               遊戲內容（純資料，改題目改這裡）
    drugs.js          藥品、第四天庫存、作業時間、針劑規格
    people.js         病人、開立者、退回理由
    jobs.js           固定的工作項目
    helpers.js        站內幫手的原型與生成
    support.js        支援作業、CBRNE、追加的諮詢與衛教題庫
    field.js          物流到訪、語言不通的傷患、領藥窗口、EMT 協助
    rx-bank.js        處方題庫
  scenario.js         以種子隨機編排這一場
  game/               遊戲規則
    state.js          遊戲狀態、紀錄、職能計分
    dispense.js       空檔工作、數藥、調劑、替代、退回
    station.js        領藥、走動所見、維安、支援／CBRNE／語言／窗口／物流
    helpers.js        幫手的獨立作業、對話與作息
    events.js         突發事件、冷鏈、空襲威脅
    loop.js           主迴圈與畫質自動調整
    ending.js         20:00 交班、夜間、AAR
  ui/
    docs.js           開場簡報與設計文件
    render.js         各面板的繪製
  scene3d.js          three.js 三維場景
  main.js             對話框、版面判斷、事件繫結、啟動
```

所有 JS 都是一般的 `<script>`（不是 ES module），共用同一個全域範圍，**載入順序就是相依順序**——新增檔案時請照 `index.html` 裡的順序插入。這樣做是為了讓遊戲在 `file://` 下雙擊就能開，不需要本機伺服器或打包工具。
